# Sky Flowers Malawi  

**E-commerce website for satin flowers**  
Live site → https://skyflowers-malawi.vercel.app 

### Features
- Real-time flower catalog with images & prices in MKW  
- Fully working cart (add, remove, quantity)  
- One-click WhatsApp checkout (+265 990 406 625)  
- Dark mode toggle (sun/moon)  
- Floating cart button with live count  
- Admin panel to add/delete flowers (`/admin.html`)  
- Responsive — looks fire on phone, tablet, desktop   

### Tech Stack
- Frontend: Vanilla HTML + CSS + JavaScript  
- Backend: Node.js + Express  
- Database: MySQL (PlanetScale in production)  
- Hosting: Vercel (frontend) + Railway (backend)  
- Icons: Font Awesome
